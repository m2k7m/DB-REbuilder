# DB-REbuilder

DB-REbuilder is a payload designed for the PS4 that solves the issue of applications disappearing from the main menu on jailbroken consoles.

## Download

To download the latest version, please visit the [Releases Page](https://github.com/m2k7m/DB-REbuilder/releases).

## How to Run

1. If you have Python installed, you can use the [`payload_sender.py`](https://github.com/m2k7m/DB-REbuilder/blob/main/payload_sender.py) included in this project.
2. You can use [Al-Azif/hermes-link](https://github.com/Al-Azif/hermes-link/releases/latest).
3. Put the payload in `/data/payloads` using FTP (or use a USB drive at `usb/payloads/`), then use one of the software options below:
   * [Vuemony/vue-after-free](https://github.com/Vuemony/vue-after-free/releases/latest) (full version)
   * [Al-Azif/ps4-payload-guest](https://github.com/Al-Azif/ps4-payload-guest/releases/latest)
   * [GoldHEN v2.4b18.10+](https://ko-fi.com/s/d64a916507)
